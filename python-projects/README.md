
# Python Projects

A collection of four Python projects I built while learning programming fundamentals, problem-solving, and code organization.

These projects helped me practice Python, organize my code, and understand how different programming concepts work.

## Projects

| Project | Description | Key Concepts |
|---|---|---|
| [Rock, Paper, Scissors](rock-paper-scissors/) | Classic game against the computer, featuring ASCII art. | Randomization, lists, conditional logic |
| [Password Generator](password-generator/) | Generates randomized passwords based on user-selected character quantities. | Loops, lists, string manipulation |
| [Simple Calculator](simple-calculator/) | Performs basic arithmetic operations. | Functions, return values, conditions |
| [Number Guessing Game](number-guessing-game/) | Guess a randomly generated number with limited attempts and difficulty levels. | Functions, while loops, control flow |

## Technologies

- Python 3
- Visual Studio Code
- Git and GitHub

## Getting Started

1. Install Python 3.
2. Open the folder of the project you want to run.
3. Run the application from the terminal:

```bash
python main.py
```

Each project includes its own README with additional information.
