
# Simple Calculator

A command-line calculator built with Python to perform basic arithmetic operations.

This project focuses on using functions, conditional statements, and user input to organize a simple and interactive application.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Support for decimal numbers
- Handle division by zero
- Display an error message for invalid operations

## Python Concepts

- Function definitions with `def`
- Return statements
- Function parameters and arguments
- Conditional statements (if, elif, else)
- User input and float conversion
- Basic arithmetic operations

## How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in this project's folder.
3. Run:

```bash
python main.py
```

4. Enter the first number.
5. Choose an operation (+, -, *, /).
6. Enter the second number.
7. The calculator will display the result.

## Example

```text
Enter the first number: 10
Choose an operation (+, -, *, /): *
Enter the second number: 5
Result: 50.0
```
