
# Password Generator

A Python application that generates randomized passwords based on the number of letters, numbers, and symbols selected by the user.

This project demonstrates fundamental programming concepts through a simple, interactive command-line application.

## Features

- Choose the number of letters, numbers, and symbols.
- Generate a password using randomly selected characters.
- Shuffle the characters to create a mixed sequence.
- Display the generated password in the terminal.

## Python Concepts

- Random number generation
- For loops
- Lists and the append() method
- String manipulation with join()
- User input and type conversion
- List shuffling

## How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in this project's folder.
3. Run:

```bash
python main.py
```

4. Enter the desired number of letters, numbers, and symbols.
5. The generated password will appear in the terminal.

## Important Note

This application uses Python's `random` module for educational purposes.

It is not designed for cryptographically secure password generation and should not be used to create passwords for real accounts.
