
# Number Guessing Game

An interactive Python game where the player tries to guess a randomly generated number between 1 and 100.

The game includes two difficulty levels, limited attempts, and feedback to help the player find the correct number.

## Features

- Generate a random number between 1 and 100.
- Choose between two difficulty levels:
  - Easy: 10 attempts.
  - Hard: 5 attempts.
- Receive feedback when a guess is too high or too low.
- Display the number of remaining attempts.
- Win by guessing the correct number.
- Reveal the answer when all attempts are used.
- Handle invalid difficulty selections.

## Python Concepts

- Functions and return values
- Random number generation
- While loops
- Conditional statements (if, elif, else)
- Break statements
- Variables and counters
- User input and type conversion

## How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in this project's folder.
3. Run:

```bash
python main.py
```

4. Choose a difficulty level: `easy` or `hard`.
5. Enter a number between 1 and 100.
6. Follow the hints until you guess correctly or run out of attempts.
