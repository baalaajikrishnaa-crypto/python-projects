
# Rock, Paper, Scissors

A classic Rock, Paper, Scissors game built with Python, where the player competes against the computer.

The game uses ASCII art to display each choice directly in the terminal.

## Features

- Play against a computer-generated choice.
- Choose rock, paper, or scissors.
- Display choices using ASCII art.
- Determine whether the player wins, loses, or draws.
- Handle choices outside the valid range.

## Python Concepts

- Random number generation
- Lists and indexing
- Conditional statements
- User input
- ASCII art and terminal output

## How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in this project's folder.
3. Run:

```bash
python main.py
```

4. Enter your choice:
   - `0` - Rock
   - `1` - Paper
   - `2` - Scissors

## About

I built this game while learning Python to practice random number generation, lists, conditional statements, and user input.
